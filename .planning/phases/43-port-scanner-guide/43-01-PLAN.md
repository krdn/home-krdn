포트 스캔 관련 타입과 Zod 스키마를 정의합니다.

1. SystemPort 타입 정의:
```typescript
interface SystemPort {
  port: number;
  protocol: 'tcp' | 'udp';
  state: 'LISTEN';
  process?: string;   // 프로세스 이름 (권한 있을 때만)
  pid?: number;       // 프로세스 ID (권한 있을 때만)
  address?: string;   // 바인딩 주소 (0.0.0.0, 127.0.0.1 등)
}
```

2. DockerPortBinding 타입 정의:
```typescript
interface DockerPortBinding {
  hostPort: number;
  containerPort: number;
  protocol: string;
  containerId: string;
  containerName: string;
  containerState: string;  // running, exited 등
}
```

3. PortComparisonResult 타입 정의:
```typescript
interface PortComparisonResult {
  registeredAndActive: Array<{
    registered: PortRegistryDto;
    docker?: DockerPortBinding;
  }>;
  registeredButInactive: PortRegistryDto[];
  unregisteredButActive: Array<{
    docker: DockerPortBinding;
    system?: SystemPort;
  }>;
  summary: {
    totalRegistered: number;
    activeCount: number;
    inactiveCount: number;
    unregisteredCount: number;
  };
}
```

4. PortScanResult 타입 정의:
```typescript
interface PortScanResult {
  system: SystemPort[];      // ss 명령어 결과
  docker: DockerPortBinding[];  // Docker API 결과
  scannedAt: string;         // ISO 날짜
}
```

5. Zod 스키마 정의:
- SystemPortSchema
- DockerPortBindingSchema
- PortScanResultSchema

  <name>Task 2: Port Scanner 서비스 구현</name>
  <files>src/lib/port-scanner.ts</files>
  <action>
포트 스캔 서비스 레이어를 구현합니다.

1. ss 출력 파싱 함수 (순수 함수, 테스트 가능):
```typescript
/**
 * ss -tlnH 출력을 파싱합니다.
 * @param output ss 명령어 출력
 * @returns 파싱된 SystemPort 배열
 */
export function parseSsOutput(output: string): SystemPort[]
```

- LISTEN 상태인 포트만 추출
- 로컬 주소에서 포트 번호 추출 (IPv4/IPv6 모두 처리)
- 프로세스 정보 추출 (있는 경우)
- 파싱 실패 시 빈 배열 반환 (graceful degradation)

2. 시스템 포트 스캔 함수:
```typescript
/**
 * 시스템에서 열린 TCP 포트를 스캔합니다.
 * 컨테이너 내부에서 실행 시 컨테이너 네임스페이스 포트만 표시됨
 */
export async function scanSystemPorts(): Promise<SystemPort[]>
```

- `ss -tlnH 2>/dev/null || netstat -tlnp 2>/dev/null` 실행
- execSync 사용 (기존 system.ts 패턴)
- 에러 시 빈 배열 반환

3. Docker 포트 바인딩 조회 함수:
```typescript
/**
 * 모든 Docker 컨테이너의 호스트 포트 바인딩을 조회합니다.
 */
export async function getDockerPortBindings(): Promise<DockerPortBinding[]>
```

- listContainers(true) 호출하여 모든 컨테이너 조회
- ContainerInfo.ports 배열에서 "hostPort:containerPort/protocol" 파싱
- 컨테이너 ID, 이름, 상태 포함

4. Registry와 비교 함수:
```typescript
/**
 * PortRegistry에 등록된 포트와 실제 활성 포트를 비교합니다.
 */
export async function comparePortsWithRegistry(): Promise<PortComparisonResult>
```

- getAllPorts()로 등록된 포트 조회
- getDockerPortBindings()로 Docker 포트 조회
- scanSystemPorts()로 시스템 포트 조회 (참고용)
- 비교 결과 분류:
  - registeredAndActive: 등록됨 + Docker에서 활성
  - registeredButInactive: 등록됨 + Docker에 없음
  - unregisteredButActive: 미등록 + Docker에서 활성

system.ts의 parseProcStat, parseNetDev 패턴을 참고하여 순수 함수로 구현합니다.
