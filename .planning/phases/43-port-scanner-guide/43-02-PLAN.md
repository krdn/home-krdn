### PortComparison.tsx
등록 포트 vs 실제 포트 비교 결과를 시각화합니다.

UI 구성:
- 요약 카드: 등록 총 | 활성 | 비활성 | 미등록
- 3개 섹션:
  1. "정상: 등록 + 활성" (registeredAndActive)
     - 테이블: port | projectName | container | status
     - Badge: 녹색 "활성"
  2. "주의: 등록 + 비활성" (registeredButInactive)
     - 테이블: port | projectName | environment | lastUpdated
     - Badge: 노란색 "비활성"
     - 도움말: "등록되었지만 현재 실행 중이지 않은 포트입니다"
  3. "미등록: 미등록 + 활성" (unregisteredButActive)
     - 테이블: hostPort | containerName | containerPort
     - Badge: 주황색 "미등록"
     - 도움말: "PortRegistry에 등록되지 않은 포트입니다. 등록을 권장합니다."

```typescript
export function PortComparison() {
  const { comparison, isLoading, error, refetch } = usePortComparison();
  // ...
}
```
