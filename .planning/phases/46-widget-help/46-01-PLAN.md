**widget-system-monitor (시스템 모니터):** 기존 placeholder 업데이트
- 제목: "시스템 모니터"
- 내용:
  - 목적: CPU, 메모리, 디스크, 업타임을 실시간으로 표시
  - 주요 지표:
    - CPU: 현재 사용률 (%) - 모든 코어 평균
    - 메모리: 사용 중 / 전체 (GB)
    - 디스크: 사용 중 / 전체 (GB)
    - 업타임: 시스템 가동 시간
  - 상태 색상:
    - 🟢 녹색 (0-50%): 정상
    - 🔵 파란색 (50-70%): 보통
    - 🟡 노란색 (70-90%): 주의
    - 🔴 빨간색 (90-100%): 위험
  - 팁: 💡 알림 설정에서 임계값 알림 규칙 추가 가능
- 관련 링크: /admin/alerts

**widget-container-stats (컨테이너 통계):** 기존 placeholder 업데이트
- 제목: "컨테이너 통계"
- 내용:
  - 목적: Docker 컨테이너 실행 상태 요약
  - 주요 지표:
    - Running: 현재 실행 중인 컨테이너 수
    - Stopped: 정지된 컨테이너 수
    - Total: 전체 컨테이너 수
  - 상태 색상:
    - 🟢 녹색: 실행 중 (running)
    - 🔴 빨간색: 중지됨 (stopped)
    - 🟡 노란색: 재시작 중 (restarting)
  - 팁: 💡 상세 관리는 Admin > Containers 페이지에서
- 관련 링크: /admin/containers

**widget-network-chart (네트워크 차트):** 기존 widget-network-status 업데이트
- 제목: "네트워크 트래픽"
- 내용:
  - 목적: 네트워크 송수신 트래픽을 시계열 그래프로 표시
  - 주요 지표:
    - RX (수신): 들어오는 네트워크 트래픽 (KB/s)
    - TX (송신): 나가는 네트워크 트래픽 (KB/s)
  - 그래프 읽기:
    - X축: 시간 (최근 N분)
    - Y축: 트래픽 양 (KB/s)
    - 면적 채움: 전체 트래픽 규모 시각화
  - 팁: 💡 급격한 트래픽 증가는 비정상 활동 징후일 수 있음
  - 문제 해결: 네트워크 트래픽이 0이면 Docker 네트워크 설정 확인

**widget-process-chart (프로세스 차트):**
- 제목: "프로세스 메트릭"
- 내용:
  - 목적: CPU/메모리 사용량 히스토리를 시계열 그래프로 표시
  - 주요 지표:
    - CPU: 시간별 CPU 사용률 추이
    - Memory: 시간별 메모리 사용률 추이
  - 그래프 읽기:
    - X축: 시간 (최근 N분)
    - Y축: 사용률 (%)
    - 라인 색상: CPU(파란색), Memory(초록색)
  - 팁: 💡 추세 확인으로 리소스 부족 예측 가능
  - 문제 해결: 지속적인 90%+ 사용률은 스케일업 필요 신호

**widget-port-scanner (포트 스캐너):**
- 제목: "포트 스캐너"
- 내용:
  - 목적: Docker 컨테이너 및 시스템의 활성 포트를 실시간 스캔
  - 주요 기능:
    - Docker 포트: 컨테이너 포트 바인딩 목록
    - 시스템 포트: ss 명령어로 조회한 활성 포트
    - 마지막 스캔: 스캔 시간 표시
  - 소스 구분:
    - 🐳 Docker: 컨테이너 포트 바인딩
    - 🖥️ System: 시스템 레벨 포트 (IPv4/IPv6)
  - 팁: 💡 새로고침 버튼으로 최신 상태 조회
  - 문제 해결: 포트가 안 보이면 Docker 데몬 상태 확인

**widget-port-comparison (포트 비교):**
- 제목: "포트 비교"
- 내용:
  - 목적: 등록된 포트와 실제 활성 포트를 비교 분석

    - ✅ 매칭: 등록 포트가 실제로 활성화됨

    - 🔴 미등록: 활성화되어 있으나 미등록됨
  - 주요 기능:
    - 카테고리별 필터링
    - 포트 범위별 사용률 Progress Bar
  - 팁: 💡 미등록 포트는 보안 위험일 수 있으니 확인 필요
- 관련 링크: /admin/ports

  - 팁: 💡 새 프로젝트 시작 전 포트 예약 권장
